# ระบบจองโต๊ะห้องสมุด (Library Seat Reservation System)

## 1. รายละเอียดโปรเจกต์

ระบบจองโต๊ะห้องสมุด พัฒนาขึ้นเพื่อให้ผู้ใช้งานสามารถตรวจสอบสถานะโต๊ะ จองโต๊ะ และจัดการการจองได้ผ่านระบบออนไลน์ โดยมีหน้า Admin สำหรับจัดการข้อมูลการจอง

## 2. เครื่องมือที่ใช้พัฒนา

- HTML
- CSS
- JavaScript
- Visual Studio Code
- Node.js & Express.js
- PostgreSQL
- GitHub

## 3. วิธีติดตั้งและตั้งค่าโปรเจกต์
1. ดาวน์โหลดหรือ Clone โปรเจกต์ลงในเครื่อง และเปิดโฟลเดอร์โปรเจกต์ด้วย  Visual Studio Code และ เปิด Terminal ใน VS Code  ติดตั้งแพ็กเกจที่จำเป็นด้วยคำสั่ง -npm install
-node seed.js
-npm start
2. ติดตั้ง PostgreSQL และเปิดโปรแกรม **pgAdmin** เพื่อสร้างฐานข้อมูลสำหรับระบบ 
3. สร้างไฟล์ .evn  ที่โฟลเดอร์หลักของโปรเจกต์ และกำหนดค่าการเชื่อมต่อฐานข้อมูล:
env

  port: process.env.DB_PORT,
  database: process.env.DB_NAME,

## 4. วิธีใช้งาน

1. เปิดไฟล์หน้าเว็บไซต์
2. เข้าสู่หน้าระบบจองโต๊ะ
3. เลือกโต๊ะที่ต้องการจอง
4. กรอกข้อมูลผู้ใช้งาน
5. กดยืนยันการจอง
6. สามารถตรวจสอบสถานะการจองได้
สำหรับนักศึกษา (User): เข้าสู่หน้าระบบจองโต๊ะ -> เลือกวันที่และรอบเวลา (เช้า / บ่าย / เย็น-ค่ำ / ดึก) -> ตรวจสอบสถานะโต๊ะว่าง -> เลือกโต๊ะและยืนยันการจอง -> ยืนยันเข้าใช้งานภายใน 10 นาที

สำหรับเจ้าหน้าที่ (Admin): เข้าสู่ระบบจัดการ -> ตรวจสอบสถานะโต๊ะทั้งหมด -> จัดการสถานะโต๊ะ (โหมดซ่อมบำรุง/ปิดปรับปรุง) -> ตรวจสอบประวัติการจอง -> ทำรายการจองแทนผู้ใช้งาน (Walk-in) ที่หน้าเคาน์เตอร์
